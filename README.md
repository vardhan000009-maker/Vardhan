XENØ is an award-winning, experimental, cinematic sci-fi WebGL digital experience built to transcend traditional web design. The project abandons standard website layouts in favor of an interactive alien universe, custom synth audio engine, real-time 3D Three.js canvas environments, and a bio-interactive cursor engine.

🌟 Key Features

Procedural 3D WebGL Canvas Engine (Three.js):

First Contact Transmission: Procedural alien eye with metallic iris rings, glowing pupil, floating orbital rings, and smooth real-time cursor tracking.

Main Universe Engine: Procedural extraterrestrial planet crystal core, volumetric particle starfield, floating orbital structure nodes, dynamic camera target lerping, and fog volume effects.

Custom Web Audio API Synth Engine:

Zero-dependency audio synthesizer generating deep binaural sub-bass drones (43.2 Hz), high-frequency telemetry chirps, dimensional warp transition sweeps, and warning alarms.

Live top-right audio equalizer frequency visualizer.

Bioluminescent Particle Cursor Engine:

Real-time 2D canvas pointer tracking emitting glowing particle trails with state-morphing reactions.

Interactive Section Nodes:

THE CORE: Dynamic planetary telemetry HUD, real-time signal monitors, and experimental editorial typography.

THE ARCHIVES: Extraterrestrial artifact project grid with real-time wireframe inspection modals.

THE SPECIES: Entity dossier with interactive bio-scan mode switches (Normal, Thermal, Quantum Grid).

THE SIGNAL: Encrypted telemetry transmission form with real-time payload encryption progress.

THE VOID (Forbidden Crimson Easter Egg):

Secret high-level security clearance environment featuring crimson lighting, countdown timer, glitch matrix logs, and interactive command terminal simulator
